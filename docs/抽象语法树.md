# 抽象语法树 AST

编译成功后选择右侧“语法树”页，即可看到编译器实际生成的AST节点连线图。
此页会暂时收起运行时面板，为语法树留出更高的画布；切换到其他分析页后恢复运行时面板。
树中保留声明、赋值、运算、分支、循环、数组访问与过程调用等语义结构，省略分号和括号等语法细节。
例如 `2 + 3 * 4` 中，乘法节点位于加法节点下方，反映先乘后加的结构。

- 滚轮：缩放，拖动画布：平移。
- 适应窗口：展示整棵树；原始大小：恢复清晰的原始比例。
- 大图查看：在独立大窗口浏览，适用于过程和循环较多的程序。
- 点击蓝色节点：高亮其源码区间，顶部显示节点名称和起始行列。
- 灰色节点：程序、分程序、目标、分支等结构分组；没有独立源码区间时不提供点击定位。
- 较长的节点名称会省略显示，悬停可查看完整名称。

修改源码、切换编译选项或重新载入示例后，旧图会清空。编译失败时不展示可能不完整的AST，诊断和语法轨迹仍可用于分析错误。
图形节点保存显示数据与源码区间，不持有编译结果对象的地址。

“语法轨迹”展示真实分析事件的顺序，并支持逐步回放；“语法树”展示分析完成后得到的程序结构。
目前两者是独立视图，AST图不随轨迹事件逐步生长。

界面回归测试检查运算嵌套关系、节点无重叠、点击定位、编辑后失效、编译失败清空，以及数组、过程、分支和循环等构造。
