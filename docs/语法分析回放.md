# 语法分析回放

编译源码后，点击右侧的“语法轨迹”页。默认显示完整分析结果。

点击“重置”回到第0个事件，随后点击“下一步”，按顺序查看进入规则、消费词法单元、完成规则和错误等事件。
“上一步”恢复上一个事件的节点与状态；“播放”按慢速、正常或快速推进，“暂停”停在当前事件，“全部”恢复完整结果。
播放结束后再次点击“播放”，会从头开始。

进度行显示当前事件数与总数，详情行显示当前事件、源码行列和嵌套深度。
树中选中当前事件对应的规则或词法单元，源码同步高亮。规则的完成事件会选中并更新原规则节点。
树只展示当前进度之前的事件，尚未发生的规则不会提前显示为完成。

切换分析选项卡会暂停播放。修改源码、切换示例、打开文件或改变编译选项后，旧轨迹被清空，需要重新编译。
编译失败时已收集的轨迹仍可以回放，帮助定位错误。Recover事件只有分析器实际调用同步恢复接口时才会出现。

回放使用编译器实际记录的事件，不会重新运行语法分析器，也不会改变程序的编译结果或虚拟机状态。
顶部工具栏的“单步”依然表示执行一条P-Code；语法分析请使用此页内部的“下一步”。
本功能展示递归下降调用轨迹，不是独立的AST图或LR分析表。

## 回归验证

开启GUI与测试构建后，CTest中的 `parse_replay` 使用Qt离屏模式运行界面回归检查，覆盖：

- 无轨迹时的按钮状态、重置与首事件显示。
- 后退再前进的树状态一致性、完整回放与原始总览一致性。
- 播放启动、自动推进、暂停、结束重播和切页暂停。
- 源码高亮、编辑后失效，以及编译失败时的错误事件回放。

运行测试时需要Qt和MinGW运行库目录位于PATH中。
