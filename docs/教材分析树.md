# 教材风格分析树

“教材分析树”页参照课本自顶向下分析树的呈现方式：白底、黑色文字节点、直线分支，无矩形框。
非终结规则按实际递归下降层次展开，叶节点显示消费的词法单元原文，保留关键字、运算符、括号、分号和句点。
当前步骤对应的节点标红。点击带源码区间的节点可定位源程序。

此视图使用本项目分析器的真实Enter、Consume、Exit等事件构建，而不是套用照片中S、A、c、d的示例文法。
程序、分程序、表达式、项、因子等名称对应本项目的分析函数；扩展运算还保留逻辑项、关系式等层级。
部分规则允许为空，记录中没有消费事件时会保留该规则节点，不额外虚构终结符或推导步骤。

## 操作

编译后选择“教材分析树”。默认显示完整树；点击“重置”后，通过“下一步”观察自顶向下的展开。
“上一步”恢复到上一条事件，“播放”自动推进，“暂停”停止，“全部”恢复总览。
操作与“语法轨迹”共享同一事件进度；速度沿用“语法轨迹”页的设置。
切换到这两个分析过程视图之外的选项卡会暂停播放。
滚轮缩放、拖动画布；较大的树可使用“大图查看”。

一次“下一步”表示一条真实分析事件，不等于一次完整产生式替换。完成规则的事件可能只改变当前红色节点，而不增加分支。
编译失败时可查看已记录的部分分析树与错误事件。修改源码后旧图清空，需重新编译。

“抽象语法树”页继续提供省略语法细节的AST，适合说明运算优先级和程序语义结构。
