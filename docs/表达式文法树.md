# 表达式文法树 E T F

此页按教材常见的表达式文法生成具体语法分析树。内部节点使用E、T、F，运算符和括号是单独的终结符叶节点。
它不是将调用轨迹中的中文名称替换成字母，也不是省略中间层的AST。

```text
E → E + T | E - T | T
T → T * F | T / F | T % F | F
F → ( E ) | id | num | + F | - F
```

其中E为表达式、T为项、F为因子。叶节点显示实际标识符或数值，例如a、b、3，对应文法中的id或num；悬停与点击节点可查看源码信息。
`a + b * c`使用的正是教材中的加乘子文法，树形为E下面连接E、+、T，右侧T下面连接T、*、F。

## 操作

1. 输入完整PL/0程序并编译成功。
2. 打开“表达式文法树”，在下拉框选择要查看的算术表达式，条目包含源码行列。
3. 默认展示第一个可用表达式的完整树。“重置”回到仅含E的初始状态；“下一步”展开一个最左非终结符，“上一步”恢复上一步。
4. “播放”每700毫秒推进一次产生式，“暂停”停止，“全部”恢复完整树。支持大图查看、滚轮缩放、拖动与源码定位。

括号中的子表达式也可单独选择。表达式选择后从E开始，可点击“全部”查看完整结构。
编译失败、修改源码或改变编译选项后，旧表达式列表与旧图会清空。

## 与编译器的关系

待展示的词法单元来自实际编译过程中消费的表达式Token，另按上方明确列出的等价算术文法构造E/T/F树。
展示树采用左递归形式，以体现左结合；实际递归下降分析器使用循环消除左递归，执行轨迹见“语法轨迹”页。
因此此页的播放是教材文法的最左推导演示，并不声称每一步等于编译器的一次函数调用。

此文法不包含布尔逻辑、关系运算、数组访问与过程调用。这些表达式不会被错误套入E/T/F文法，完整结构请查看“教材分析树”或“抽象语法树”。
没有可用算术表达式时显示提示，不生成虚构的树。
